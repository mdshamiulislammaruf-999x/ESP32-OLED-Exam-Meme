# ESP32 OLED Exam Meme Animation

A custom animated meme project using an ESP32 and a 1.3-inch 128x64 SH1106 OLED display.

## Hardware

- ESP32 Dev Module
- 1.3-inch 128x64 OLED
- I2C interface

## OLED Configuration

- Controller: SH1106
- Resolution: 128x64
- I2C Address: 0x3C
- SDA: GPIO 21
- SCL: GPIO 22

## Features

- Custom OLED bitmap animation
- Multiple animation frames
- Exam reminder message
- Crying cat meme animation
- Frame timing control
- Images stored in ESP32 program memory

## Animation Sequence

1. Girl animation
2. Waiting/transition animation
3. "YOU HAVE EXAM"
4. "TOMORROW"
5. "GO AND STUDY!"
6. Crying cat
7. Ending screen

## Software

- Arduino Framework
- PlatformIO
- U8g2 library
- C++
